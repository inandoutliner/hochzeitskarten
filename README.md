# Hochzeitskarten

Plotter-App für Hochzeitskarten, am Handy bedienbar: Vorlagen zum Schneiden und Falzen (Klappkarte, Fensterkarte, Torkarte mit Herzverschluss, Pop-up, Geldgeschenk, Leporello, dazu Einleger, Umschlag, Banderole), Moiré-Muster, Schrift im Muster, Stift-Schrift und Linienband. Ausgabe als SVG für den Cricut (Schneiden, Falzen, zwei Stifte).

Online: https://inandoutliner.github.io/hochzeitskarten/

Einstrich-Schriften: Hershey-Schriften (Dr. A. V. Hershey) und EMS-Schriften (SIL Open Font License), Hinweise und Lizenztexte stehen in der index.html.
